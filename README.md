# Analyseur de matchs

Appli mobile installable (PWA) qui analyse les confrontations directes entre deux équipes de football : buts par match, bilan des victoires, tendances de buts et conclusion.

- Données : API-Football (clé gratuite à saisir dans l'appli, stockée uniquement sur le téléphone)
- Secours : lecture de capture d'écran ou résultats collés

2. Créer le relais sur Cloudflare
  1. Ouvre dash.cloudflare.com et connecte-toi.
  2. Dans le menu, touche Workers & Pages (parfois sous Compute).
  3. Touche Create, puis Start with Hello World! (ou « Create Worker »).
  4. Donne le nom analyseur, puis touche Deploy.
  5. Touche Edit code. Efface tout le code affiché, colle celui que tu as copié, puis touche Deploy.
  6. Copie l'adresse du relais, du type https://analyseur.ton-nom.workers.dev.
3. Brancher le relais dans l'appli
  1. Ouvre l'appli, touche Réglages.
  2. Colle l'adresse dans Adresse du relais matchendirect, puis touche Enregistrer.
  3. Tu dois voir Relais OK.
